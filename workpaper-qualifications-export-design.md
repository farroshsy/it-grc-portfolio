# Workpaper, Qualifications, and Executive Export — Design Record

## Simulated Audit Workpaper

The workpaper will be a **Simulated Case Study** attached to the audit-room experience. It will model an assessment of time-bound privileged access by recording the control objective, population and sample selection, test steps, observed evidence, exceptions, conclusion, reviewer, and follow-up linkage. It demonstrates a repeatable workpaper format without representing an actual audit file, sample, or audit conclusion.

NIST SP 800-53A Rev. 5 provides adaptable assessment procedures that organizations can tailor to their risk-management needs. The workpaper will use this concept as methodological context; it will not reproduce NIST procedures or claim alignment, certification, or assurance.[1]

## Skills and Certifications

The dedicated page will distinguish **portfolio-demonstrated skills** from **formal credentials**. Since no candidate certification details were supplied, it will not invent them. It will instead present the portfolio’s application-focused capabilities for the target IT GRC / fintech role and state that formal certifications should only be added once verified by the candidate. This avoids turning simulated evidence into a claim of employment experience or certification.

## Executive Briefing PDF

The PDF export will be generated client-side from the same tRPC-backed executive-briefing records used on the page. It will be a compact, one-page, downloadable management packet with metrics, top risks, decision prompts, an evidence-readiness note, generation date, and a simulated-case disclaimer. It will not use local server files or represent an audit report.
